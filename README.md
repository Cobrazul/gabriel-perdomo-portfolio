# Portfolio Gabriel Perdomo

Portfolio personal hecho con Next.js y CSS puro, listo para desplegar en Vercel.

## Cómo correrlo localmente

```bash
npm install
npm run dev
```

Luego abrir: http://localhost:3000/es

## Deploy en Vercel

1. Subir este proyecto a GitHub.
2. Entrar a https://vercel.com/new.
3. Importar el repositorio.
4. Framework: Next.js.
5. Deploy.

## Editar datos

El contenido principal está en:

`app/[locale]/page.tsx`

El CV PDF está en:

`public/cv-gabriel-perdomo.pdf`
